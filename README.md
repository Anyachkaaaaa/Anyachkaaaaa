# Anyachkaaaaa

## About

Я собираю сайты, сервисы, desktop-проекты, automation-инструменты и рабочую инфраструктуру в единые, аккуратные системы.  
Мне нравится, когда проект ощущается как законченный продукт: от интерфейса и логики до деплоя, структуры и общего стиля.

Основной фокус:
- fullstack-разработка
- frontend и UI
- backend и API
- automation и tooling
- desktop-направление
- dev-infra и рабочая архитектура
